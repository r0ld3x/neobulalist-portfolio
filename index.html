FREQUENTLY ASKED_QUESTIONS

How much does a website or app cost?

It depends on features. After a short call I send a fixed quote with a clear breakdown, so you know the full cost before any work starts.

How long will my project take?

A business website usually takes 1–3 weeks. An MVP web or mobile app usually takes 4–10 weeks. Automation scripts can often be delivered in days.

Can you build both the website and the mobile app?

Yes. I build the website, Android & iOS apps and the shared backend they run on, so everything works together from day one.

Can you automate my repetitive work or scrape data for me?

Yes. I write Python automation scripts, web scrapers, bots and scheduled jobs that collect data, fill forms, generate reports or connect your tools, so the work runs without manual effort.

Can you set up hosting, servers and DevOps?

Yes. I handle Docker, Kubernetes, CI/CD pipelines and AWS or VPS setup, with monitoring, backups and scaling.

Can you check my website or app for security issues?

Yes. I review web apps and APIs against the OWASP Top 10, fix vulnerabilities, and harden authentication and access control.

Do I own the code?

Yes, 100%. You get the full source code, hosting access and documentation when the project is handed over.

Do you offer support after launch?

Yes. I offer ongoing maintenance, bug fixes, updates and new features after launch, either on a monthly plan or per task.

Do you work with clients outside India?

Yes. I work remotely with clients worldwide and communicate in English and Hindi.
